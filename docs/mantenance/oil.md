# 真空ポンプのオイル交換方法

## 1. 準備するもの

- 真空ポンプ用オイル
- 廃オイルを回収する容器（2 L以上で余裕のあるもの）
- 長パス
- ダンボール
- ニトリル手袋

## 2. 操作手順

### ① オイル交換の準備

真空ポンプを停止し、電源を切る。取扱説明書に従って真空を解除する。

床にオイルがこぼれる可能性があるため、あらかじめポンプの周囲にダンボールを敷いておく。

### ② オイル注入口の蓋を開ける

真空ポンプ上部のオイル注入口の蓋を開ける。

### ③ 古いオイルを排出する

1. 排出口の下に廃オイル回収用の容器を置く。
2. 排出口のコックをひねり、古いオイルを排出する（約2 L）。
3. オイルの排出が完了したら、コックをしっかりと閉める。

### ④ 新しいオイルを注入する

使用しているオイルは以下の通り。

- 真空ライン：PHIL用オイル
- LC-MS：Ultra Guard 19

**異なる種類のオイルを混ぜないように注意すること。**

1. オイル注入口から真空ポンプ用のオイルを注入する。
2. 長パスの外側を伝わせながらオイルを注ぐと、スムーズに注入できる。
3. オイル量の確認窓を見ながら、油面がMINの目盛りを超え、規定の範囲内に収まるまで注入する。
4. オイル注入口の蓋を閉める。

### ⑤ 最終確認

- 排出口のコックが閉まっていることを確認する。
- オイル注入口の蓋が閉まっていることを確認する。
- オイル量が適切であることを確認する。
- オイルが漏れていないことを確認する。
